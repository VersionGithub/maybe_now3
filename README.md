# Frame Windows

Считает, сколько кадров есть на каждый клик макроса `.gdr2`.

## Как пользоваться
1. В настройках мода (Geode -> Frame Windows) выбери файл макроса `.gdr2`.
2. Зайди на нужный уровень и нажми **F6** (Analyze). Уровень сам встанет на паузу.
   Дождись конца (сверху пишется прогресс, F6 ещё раз = отмена). Результат сохраняется в кэш, при следующем заходе пересчёт не нужен.
3. В левом верхнем углу появятся счётчики: сколько кликов с окном 1, 2, 3, 4, 5-6, 7-8, 9-12, 13-16, 17-19 и 20+ кадров.
   `?` - клики, которые не прошли даже в оригинальном виде (макрос не совпал с уровнем).
4. Нажми **F7** (Showcase): уровень перезапустится, макрос сам проиграется,
   на месте каждого клика останется кружок с числом кадров (+ звук).

Кнопки Analyze/Showcase в меню паузы тоже есть, но работают только если сработают хуки паузы. Основной способ - F6/F7.

## Как считается окно
Для каждого нажатия оно сдвигается на N кадров раньше/позже, настоящая физика игры
прогоняется через чекпоинты, и проверяется, выживает ли игрок в течение
«Горизонта проверки» (настройка, по умолчанию 48 кадров). Окно = сколько кадров подряд работает клик.
Остальные клики макроса при проверке остаются на своих местах.

## Ограничения
- Только 240 TPS, только кнопка прыжка, не платформер.
- Это приближение: окно проверяется до конца горизонта, а не до конца уровня.
- Анализ идёт на паузе, во время него не закрывай меню паузы.
- Чекпоинты практики в GD не идеально точны, часть клика может показаться `?` из-за этого.
